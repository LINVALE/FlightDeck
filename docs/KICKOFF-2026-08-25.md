## 2. Grounded facts (verified 08-24 — build on these, don't re-derive)

**Roon API (from RoonLabs source, not memory):**
- `subscribe_zones` is CORE-WIDE for any extension — FlightDeck needs nothing from RHEOS. Zone carries
  now_playing (three_line, image_key, seek_position/length), per-output volume, is_*_allowed flags;
  `zones_seek_changed` ticks ~1Hz.
- Transport verbs: control/seek/change_volume/mute/group_outputs/ungroup_outputs/transfer_zone/play_from_here.
- **RoonApiBrowse** hierarchies: `browse, playlists, settings, internet_radio, albums, artists, genres,
  composers, search`; `input` = search box; `zone_or_output_id` required for play actions; `multi_session_key`
  for concurrent browsers (one per screen!). **No history/recently-played in the API** → FlightDeck records its
  own ledger from zone events (it sees every zone — a feature Roon's own display lacks).
- Artwork: raw HTTP `http://<core>:9330/api/image/<image_key>?scale=fit&width=…` (how RHEOS does it too).

**Lessons to carry from the RHEOS console (patterns, not code — it stays HEOS-side as RheoStat):**
- Its Roon-led control doctrine ("every gesture is a USER ACTION translated into a ROON-LED instruction").
- Its SSE protocol design (id/revision, snapshot|update|resync, Last-Event-ID, heartbeats) and opaque
  artwork-token rail are proven shapes worth re-implementing.
- CSP discipline (`default-src 'none'` + nonces) worked but forbade frameworks; FlightDeck OWNS its stack
  choice — a precompiled Preact/Lit bundle from same-origin assets is viable if it keeps a strict CSP.
- ⚠️ RheoStat cannot be iframed (`frame-ancestors 'none'`) — "adds onto" = link/hand-off only.

**Constraints discovered:**
- Mic-VU (Peter's insight: the display device's mic = honest room VU for ANY zone) needs a **secure context**
  → FlightDeck serves HTTPS from day one (self-signed + install flow, or the PWA route). Echo Show/Fire-TV
  browsers may refuse mic — tablets/phones are the reliable canvases.
- ⚖️ Roon DESTROYS a Squeezebox-class grouped zone on every ungroup_outputs — drag-drop grouping must issue
  ONE ungroup carrying every departing output, then ONE Roon-led Play, no resume witness
  (`reference_roon_ungroup_destroys_squeezebox_zone`; preset-remainder-resume.ts:3-21 has the receipts).
- Image engine v1 = palette-seeded generative canvas from album art (free, offline, CSP-safe); genAI later.
