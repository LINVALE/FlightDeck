# The TV drill

Receipts, with denominators. A drill is not passed because it looked fine once.

## I0 — pair

- [ ] `npm start`; **FlightDeck** appears in Roon → Settings → Extensions; enable it.
- [ ] The log lists every zone the Core knows (expect 18 on Peter's house).
- [ ] `data/roon-state.json` exists; restart the process and it re-pairs **without** a new prompt.
- [ ] Start from a different working directory — no stray `config.json` is created.

## I1 — the spine, the Wall, the name

- [ ] The lounge TV browser shows every zone with artwork, ordered most-recently-played first.
- [ ] Play/pause in Roon → the tile changes within 1 s.
- [ ] **Ethernet pull:** unplug the server's Ethernet for 60 s mid-track → the Wall says "catching up" within
      25 s → heals within 5 s of replug, **with no reload**. 3/3.
- [ ] **The name, 4 clients each recorded pass/fail:** `getent hosts flightdeck.local` on the host · an
      iPhone · a Windows laptop (`ping flightdeck.local`) · one Android-12+ TV.
- [ ] Start a second instance → it renames itself to `flightdeck-2.local` rather than fighting.
- [ ] **The QR has never been scanned by a real phone** — it is generated by a hand-written encoder with no
      decoder available offline. Scan it before trusting it.
- [ ] `/api/v1/health` reports the claimed name, the bound port and every URL.

## I2 — the faces and the picker

- [ ] **Side by side with `http://<core>:9330/display` on the same TV for one album.** Record what each does,
      honestly, including anything Roon's does better.
- [ ] Track change → paint within 500 ms including artwork.
- [ ] **Peter sees the artist backdrop with a real Roon banner** and rules on the gradient-map strength — in
      the mock the presence was faint enough that the no-artist fallback looked nearly identical.
- [ ] Pick a face on the TV with the remote's arrow keys, pull the power → it returns as chosen.
- [ ] Internet radio (no artist image) falls back to the blurred cover without a flash of empty.
- [ ] 2 h unattended with the screensaver enabled. **Expect this to FAIL on LG in the bare browser** — record
      it as a failure, not a caveat.

### Per-device setup (this is device setup, not code — say so)

| Device | Do this |
|--------|---------|
| Samsung | Auto Power Off → Off (re-check after firmware updates); Hide Tabs and Menu Bar → Use |
| LG | Always Show Address Bar → Off. `navigator.wakeLock` **hangs** rather than rejects here; it is raced against a 5 s timeout |
| Fire TV / Android TV | Use **Fully Kiosk**, not Silk — launch on boot, keep screen on |
| iPad | Guided Access + Auto-Lock Never; Wake Lock needs HTTPS (I3) |
| Echo Show | **Not a Face host.** Silk exits to home after 10–15 min and Amazon says the timeout cannot be disabled |

## I3 — endurance

- [ ] 48 h on the TV, then a **7-day soak with heap and RSS numbers recorded** — flat, not "looked fine".
- [ ] 6 screens live at once.
